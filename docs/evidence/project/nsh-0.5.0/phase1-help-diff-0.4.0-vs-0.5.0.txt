=== package

>       --format <FORMAT>
>           Android: what to write, an APK (installed directly) or an Android App Bundle (`aab`, uploaded to Google Play)
> 
>           Possible values:
>           - apk: An APK: installed directly (`adb install`, sideloading)
>           - aab: An Android App Bundle: uploaded to Google Play, which builds the APKs each device installs
>           
>           [default: apk]
> 
>       --arch <ARCH>
>           macOS: the processors the app runs on, `arm64` (Apple silicon), `x86_64` (Intel) or `universal` (both, in one executable). Default: this Mac's
> 
>           Possible values:
>           - arm64:     Apple silicon
>           - x86_64:    Intel
>           - universal: Apple silicon and Intel: one universal executable of both builds
>
