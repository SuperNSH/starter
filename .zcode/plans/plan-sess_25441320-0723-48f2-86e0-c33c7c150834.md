# Port nsh-starter canvas examples into ~/fo/gpui-starter

## Context

nsh-starter (this session's cwd) has a canvas area with 8 examples — sketch, frame loop, charts, WGSL shader, SVG, images+video, web view, and an uncommitted "infinite board" (`world.rs`) — plus camera-math tests. The user asked to create the interactive/infinite canvas "as well as all of the canvas examples we have already implemented in this repository" in `~/fo/gpui-starter`, except the gallery. No direction answer came back, so I'm going with the literal reading: **build the nsh-starter canvas example set in ~/fo/gpui-starter**, adapted to GPUI + gpui-kit, as one new page. gpui-starter's existing pages (InfiniteCanvas, CanvasShowcase, MultiuserCanvas, ShaderCanvas, Gallery…) stay untouched; the new page is the nsh-parity mirror, and its module doc will say so.

## Target: one new page `CanvasExamplesPage`

Following gpui-starter's documented page seams (CONTRIBUTING.md recipe + the six-touch removal list in `infinite_canvas/mod.rs:1-8`):

1. **New page module** `src/features/pages/canvas_examples/`:
   - `mod.rs` — `CanvasExamplesPage`: page frame (gpui-kit `v_flex`, `ActiveTheme` colors only), section list, provenance header, deviation captions; declares subsection modules. Colocated `mod.test.rs` for page wiring.
   - `sketch.rs` (+ `.test.rs`) — freehand strokes on `crate::ui::canvas::{Canvas, CanvasState}` via a custom `CanvasTool` (BrushTool pattern, `tool.rs:256`), color/width swatches, Undo/Clear. Undo removes the last committed shape through `edit_document` (verify removal support in `state.rs` at impl time).
   - `frame_loop.rs` (+ test) — 48 animated bars, `cx.spawn` + executor timer (~30 Hz), Pause/Reset; deterministic under `TestAppContext` manual clock (`executor.advance_clock`). Reuse the animation-driving pattern from an existing animated page (particles demo) — read it first.
   - `charts.rs` (+ test) — seeded (mulberry32) line/area + grouped bars painted with the raw `gpui::canvas()` element (precedent: `infinite_canvas/viewport.rs`); "New data" bumps seed.
   - `shader.rs` (+ test) — **adapted**: painted animated aurora bands with Pause + Calm/Swift drift controls (GPUI public API has no custom-WGSL element; note: if `src/features/pages/shaders/` exposes a cheap reusable primitive, prefer mounting it — check at impl time).
   - `svg_glyphs.rs` (+ test) — **adapted**: icon SVGs via gpui-kit `IconName` (Heart/Star/Check if present) + glyph path data painted with `gpui::Path` (curves approximated; no full SVG-arc parser).
   - `images.rs` (+ test) — `img()` with placeholder-then-fade and a tiny/sharp pair (use whatever blur the gpui `img` element actually supports; rounded frame like nsh). **Video: skipped** — no GPUI video element; recorded as a caption + module-doc deviation.
   - `world.rs` (+ test) — **the interactive infinite canvas section**, mirroring nsh-starter's `world.rs`: 3 named nodes ("Aurora"/"Notes"/"Orbit"), node cards + links + grid + axes; a `BoardTool` (CanvasTool) doing hit-test→node-drag in doc/world space, else pan; zoom in/out via `state.zoom_at(viewport_center, 1.25 / 0.8)` (engine already anchors zoom-at-point and clamps MIN_ZOOM/MAX_ZOOM); Recenter resets transform. Node labels rendered as theme-aware overlay divs positioned via `transform.to_screen` (shapes carry no text). Camera readout captions (zoom %, pan, center world coords, under-node, selection) updated from `CanvasEvent::{ViewTransformed, DocumentChanged}` subscriptions. Wheel-pan / ctrl-cmd-wheel-zoom / middle-button pan come free from `ui/canvas/element.rs`.
2. **`src/features/pages/mod.rs`** — `mod canvas_examples;` + `pub use canvas_examples::CanvasExamplesPage;`
3. **`src/shell/page.rs`** — `Page::CanvasExamples` with `title()`, `title_key() = "nav_canvas_examples"`, `host() = "canvas-examples"`, safe `IconName` (follow the shipped stand-in convention for blank-rendering icons), inserted after `MultiuserCanvas` in `all()` (index ≥ 9, so the first-9 keybindings are untouched).
4. **`src/shell/root/app_root/state.rs`** — construct `canvas_examples_page` entity + `unchecked_active_page_view` arm.
5. **`src/shell/route.rs`** — VALID_HOSTS entry `canvas-examples` (deep link `gpui-starter://canvas-examples`).
6. **`locales/en.yml` + `locales/zh-CN.yml`** — `nav_canvas_examples` + page strings in both files (qa_localization enforces parity).
7. **`tests/e2e_navigation.rs`** — add the page to the expected `Page::all()` list and page count.

## Tests

Colocated, matching `state.test.rs` style: `#[gpui_kit::test]`, no glob imports, `TestAppContext`, manual executor clock for the frame loop. Behavioral pins: sketch commit/undo/clear counts; frame-loop pause gate + tick advance under `advance_clock`; charts seed determinism + seed-bump totals; world-board pan math, node hit at zoom, node drag = screen delta / zoom, zoom-at-center keeps the world point, readout strings. Per repo rules every new test gets seen to fail once (break the code deliberately first).

## Deviations (recorded on-page + in mod.rs doc)

- Shader: painted animated bands, not WGSL (no custom-shader element on public GPUI API).
- Video: skipped; images section keeps placeholder/blur-up adaptations.
- Web view: skipped; gpui-starter has no webview element (nsh parity doc itself marks web_view as platform-hosted).
- SVG: icon assets + hand-approximated path curves instead of a full SVG path parser.
